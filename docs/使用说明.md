# haos_app 说明（以网关代码为准，App 0.3.0）

本目录是 Home Assistant **App**（原 Add-on），容器里跑 **两个进程**：

| 进程 | 入口 | 端口 | 代码 |
|------|------|------|------|
| 设备适配网关 | `python -m mcp_gw` | `:9080` | `mcp_gw/` |
| 语音桥（可选） | `voice/bridge.py` | `:8765` | 配了 `dashscope_api_key` 才启动 |

`host_network: true`。Agent 走 HA 官方 ` /api/mcp`，不要连 `:9080/mcp`（仅调试）。

---

## 三条互不替代的数据路

```text
发现设备     mDNS _mcp-sensors  → registry
             组播不到时 LAN 扫 HTTP /api/data

温湿度/在线  设备 HTTP GET /api/data（失败再 CoAP /sensors/snapshot）
             → 本 App 发 MQTT Discovery + snapshot/availability
             → HA 温度、湿度、CO2、光照、声音、在线

事件         设备自己连 Mosquitto，publish mcp_sensors/<id>/event
             → 本 App 订阅 → 规范化 → Discovery「最近事件」
             （网页 /api/mmwave.recent_events 是雷达本地缓存，100ms 轮询，不进 HA）

语音         设备 WS PCM → :8765 → 千问 ASR → HA Assist → TTS → 设备
```

`mqtt.connected=true` 只表示 **网关** 连上了 broker。  
HA 有事件，还要设备 `mqtt_connected=true`，并真正 `publish`。

## 网关启动后做什么（`mcp_gw/app.py`）

1. **广播** `_mcp-gw._tcp`、`_voice-ws._tcp`（`mdns_advertise.py`）  
   TXT：`mqtt=` 局域网 broker（禁止 `127.0.0.1`）、`mqtt_user` / `mqtt_pass`、语音 `ws=`。
2. **浏览** `_mcp-sensors._udp/tcp`（`mdns_devices.py`）→ 登记 id + IP。
3. **订阅** `mcp_sensors/+/event`（`mqtt_ha.py`）→ Discovery 转 HA。
4. **轮询快照**（`coap_poll.py`，默认 5s，多设备并行）：`/api/data`，再补 CoAP。
5. **告知设备 MQTT**（`device_mqtt.py`）  
   主路径 mDNS TXT；回退每 30s 及每次快照成功后 `POST /api/wifi` `action=mqtt`（broker + 账号）。  
   改 App 里 MQTT 配置后会强制再推。也可 `POST :9080/api/mqtt/push`。

设备 broker URI 只用 **HA 局域网 IP**（`advertise_ip` / `MQTT_ADVERTISE_HOST`），不用设备自己的 IP，也不用 `127.0.0.1`。

## 目录（该看什么）

| 路径 | 作用 |
|------|------|
| `run.sh` | 把 App 选项写成 `/app/.env`；网关连 Mosquitto 可用 `127.0.0.1`，广播给设备必须是局域网 IP |
| `mcp_gw/config.py` | 环境变量 |
| `mcp_gw/registry.py` | 设备表 |
| `mcp_gw/lan_discover.py` | mDNS 失败时扫网段 `/api/data` |
| `mcp_gw/mqtt_ha.py` | 订事件、Discovery、snapshot、在线 |
| `mcp_gw/device_mqtt.py` | 把 broker 推给设备 |
| `mcp_gw/aggregator.py` | 遗留 `/mcp`（CoAP 工具 + MQTT 事件缓存） |
| `voice/` | Assist 语音，不经 MQTT |
| `homeassistant/custom_components/` | 开发备选，**小白不用拷** |

## 第一次怎么装

1. 安装并启动 **Mosquitto**，记下登录用户（不是 HA 账号）。  
2. HA **MQTT 集成** 连同一 broker（`core-mosquitto` 即可）。  
3. 本目录拷到 `/addons/mcp_sensors_voice/`，刷新后安装 **MCP Sensors + Voice（0.4.0）**。  
4. 配置只有 4 项：
   - **MQTT 用户/密码**：与 Mosquitto 一致（未设用户则都留空）
   - **局域网 IP**：一般留空自动探测；不对再填 `192.168.1.210`
   - **阿里云语音密钥**：要说话才填  
   若从旧版升级后「应用加载出错」：先**卸载**再安装（清掉旧 options），再填这 4 项。
5. 关掉宿主机旧 `server_stack`（会抢 9080/8765）。

设备需能处理 `POST /api/wifi` `action=mqtt`，且未连上 broker 时先排队、连上再补发。

## 怎么确认

```bash
# 网关：connected=true；device_broker 应是 mqtt://192.168.1.210:1883
curl -sS http://192.168.1.210:9080/health

curl -sS http://192.168.1.210:9080/api/devices

# 设备：mqtt_connected、mqtt_broker、mqtt_event_topic
curl -sS http://192.168.1.120/api/wifi
```

HA：**设置 → 设备与服务 → 设备** 搜设备 id。  
进门后 App 日志应有 `MQTT 入站 mcp_sensors/<id>/event` 和 `设备事件 → HA Discovery`。  
`health.mqtt.events_received` 增加，「最近事件」才有值。

设备掉线再接入：串口再出现 `mqtt_hub: connected` 和 `publish mid=`。网页仍有雷达事件 ≠ 已 MQTT 上报。

## 日常

- 看数 / 问数：HA 概览、对话「温度多少」  
- 看事件：同一设备上的 **最近事件**（不是 Mosquitto 主题列表页）  
- 设备说话：网页 Assist 能答之后再用麦克风  
- 爱马仕：HA **Model Context Protocol Server**，连 `http://192.168.1.210/api/mcp`

## 不要做

- 不要拷 `custom_components`  
- 不要让爱马仕连 `:9080/mcp`  
- 不要把 MQTT 用户填成 HA 登录名  
- 不要让设备去连 `mqtt://127.0.0.1`  
- 不要用网页 `/api/mmwave` 代替 MQTT 事件进 HA
